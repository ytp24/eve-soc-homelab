4. MODBUS TCP PROTOCOL STRUCTURE (MBAP + PDU)
------------------------------------------------------------------------------
- MBAP Header (7 Bytes):
  * Bytes 0-1: Transaction ID (0x0001 - 0xFFFF)
  * Bytes 2-3: Protocol ID (0x0000 for Modbus TCP)
  * Bytes 4-5: Length (Number of following bytes)
  * Byte 6:    Unit ID (0x01)
- PDU:
  * Byte 7:    Function Code (FC 01: Read Coils, FC 03: Read Regs, FC 05: Write Coil, FC 06: Write Reg)
  * Bytes 8+:  Data payload (Register address and value)
